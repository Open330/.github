# Support

Thanks for using Open330 projects.

- **Questions and ideas** — use the *Discussions* tab of the repository you have a question about. If Discussions are not enabled there, open an issue instead.
- **Bugs and feature requests** — open an issue on that repository using the provided templates.
- **Security vulnerabilities** — do not open a public issue; see [SECURITY.md](SECURITY.md).

Please search existing issues and discussions before opening a new one.
