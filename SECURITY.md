# Security Policy

## Supported Versions

Only the latest release of each Open330 project receives security fixes.

## Reporting a Vulnerability

Please do **not** open a public issue for security problems. Report privately via either:

- **GitHub Security Advisories** — open the affected repository, go to the *Security* tab, and click *Report a vulnerability*.
- **Email** — [open330.dev@gmail.com](mailto:open330.dev@gmail.com)

Include a description, affected version(s), and steps to reproduce. We aim to acknowledge reports within **7 days** and will coordinate disclosure with you once a fix is available.
